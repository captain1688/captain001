# 香蕉猫 · 沙滩一画一毁（15秒）

用途：AI 视频生成（即梦 / 可灵 / Sora / Veo 等）。把下面「提示词」整段原样交给视频生成工具，不要改写台词和时间轴。

- 时长：15 秒
- 画幅：9:16 竖屏，4K
- 配乐：无（后期自行配乐）

## 提示词

生成一段15秒的9:16竖屏视频，4K超清，3D皮克斯动画电影风格，色彩明快鲜艳、高饱和高对比、材质细腻逼真，毛发与皮肤质感真实。场景：夏日阳光明媚的海滩，蓝天白云、微波粼粼的海浪，金黄湿润的沙滩，自然明亮的暖色调侧顺光，沙滩上有清晰阴影。

【角色设定·全程保持一致】香蕉猫：一只圆滚滚的3D卡通生物，身体是一根黄色香蕉，顶端长着白色圆润的猫头，大大的湿润泪眼、粉色小鼻子、细小胡须，短短的白色猫爪，表情夸张可爱。人类小女孩：棕色双马尾，印花朵白T恤、粉色短裤、白色凉鞋，手提一只蓝色小水桶。

第一幕（中景，0:00–0:10）一画一毁、严格逐个进行：镜头在香蕉猫与小女孩的动作间轻微平移跟随。重要规则——全程沙地上同一时间只出现一个符号；香蕉猫画完一个，小女孩立刻破坏、该符号完全消失、沙面恢复平整干净后，香蕉猫才在干净沙地上画下一个，绝不出现两个符号同时存在或重叠。
0:00–0:02.5，香蕉猫用小猫爪握着一根小木棍，认真地在湿沙上画出一个"加号（+）"；人类小女孩立刻提起蓝色小水桶，把海水浇上去，加号被冲散、完全消失，沙面恢复平整。
0:02.5–0:05，在干净沙地上，香蕉猫又画一个"爱心（❤️）"；小女孩再次浇水，爱心被冲没、彻底消失，沙面恢复干净。
0:05–0:07.5，在干净沙地上，香蕉猫接着画一个"五角星（⭐️）"；小女孩又一桶海水泼上去，五角星消失、沙面恢复干净。
0:07.5–0:10，在干净沙地上，香蕉猫最后画一个"666"；这次小女孩干脆蹲下，用手把666整个抹平、彻底毁掉，符号完全消失。
全过程一次只画一个、画完即毁、毁净再画，节奏交替、喜感递进。

第二幕（面部特写，0:10–0:12.5）香蕉猫爆发：镜头切到香蕉猫面部特写、固定不动。它因图案一再被毁猛地抬头、大眼睛瞪得溜圆、泪汪汪、张大嘴巴，又气又委屈地大声控诉，并下意识瞥向镜头（暗示"他们"就是屏幕外的观众），身体前倾发力、嘴型清晰呈现"a/o"开合，念出台词"都怪你，他们都看不到了！"，配可爱又愤怒的奶音童声，语速偏快。背景为大光圈虚化的海浪与蓝天。

第三幕（面部特写，0:12.5–0:15）人类小女孩傲娇反转：镜头切到双马尾小女孩面部特写、固定不动。她毫无歉意，先翻一个可爱的白眼、眼神侧上方瞥，随后脸颊高高鼓起、用力嘟嘴、下巴微抬，理直气壮地用嘟嘟唇小幅开合念出台词"就是不让他们看到。"，一副傲娇调皮不服气的神态。侧逆光勾勒圆润脸颊，画面定格在她傲娇表情上。

声音设计：全程不要任何背景音乐，只保留环境音与动作音效，方便后期自行配乐。环境音：海浪拍岸、远处海鸥、海风。音效：木棍划湿沙的"沙沙"声、水桶倒水的"哗啦"声、手抹湿沙的黏腻摩擦声，随一画一毁的节奏交替出现；香蕉猫爆发瞬间环境音短暂静止约半秒、仅保留一声夸张的"咚"重音效制造喜剧停顿；小女孩嘟嘴瞬间配可爱的"吧唧"挤压音效。两个角色对话声画同步、口型严丝合缝。
