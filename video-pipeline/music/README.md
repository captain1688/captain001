# 音乐库

把背景音乐按情绪放进对应的文件夹，剪辑时会自动选曲：

| 文件夹 | 适合 |
|---|---|
| `欢快/` | 玩闹、跳舞、雪人醒来这类热闹场面 |
| `温馨/` | 睡前、夜晚、拥抱 |
| `搞笑/` | 恶作剧、嘴硬、打喷嚏 |
| `梦幻/` | 魔法、星空、变身 |
| `悬念/` | 躲猫猫、偷吃、开环结尾 |

- 支持 mp3、wav、m4a、aac、flac、ogg。每个文件夹放几首，同一个工程每次会选到同一首，不同工程会分散用到不同的曲子。
- **只放你有使用权的音乐**，比如免版权音乐网站下载的、或自己买了授权的，否则发到平台可能被判侵权、静音或限流。
- 这些音乐文件**不会上传到 GitHub**（已在 `.gitignore` 里排除），只存在你电脑上。

## 剪辑时会自动做的事

- 配乐循环或截断到和视频一样长
- 开头 0.5 秒淡入，结尾 1.5 秒淡出
- 角色说话或有音效时，自动把音乐压低，说完再恢复（"闪避"）
- 整体响度统一到短视频平台常用的 −14 LUFS，不会忽大忽小

## 在 project.json 里怎么写

```json
"edit": {
  "bgm": "auto",          // auto＝按情绪自动选；也可以直接写文件名，比如 "欢快/小星星.mp3"；不要配乐就写 null
  "bgm_mood": "欢快",      // auto 时从哪个文件夹选
  "bgm_volume": 0.3,      // 音乐音量，0～1
  "duck": true            // 说话时压低音乐，默认开
}
```

（上面 `//` 后面是说明，实际文件里不能写注释。）
