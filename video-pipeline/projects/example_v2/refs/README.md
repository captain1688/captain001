# 示例工程的图片

本工程**不把图片放进仓库**：
- 角色参考图走本地素材清单：`asset:xiangjiaomao_main`，在 `video-pipeline/assets.local.json` 里指向你本机的图片（模板见 `assets.local.example.json`）。
- 两张首帧图放在本目录：`seg1_first_frame.png`、`seg2_first_frame.png`（已被 .gitignore 排除）。缺任何一张，预检和生成都会停止，不会改成纯文字生成。

首帧图提示词：

**seg1_first_frame.png**：竖屏9:16，阳光明媚的儿童房，木地板上铺着软垫，参考图中的香蕉猫坐在软垫中央，开心地朝镜头挥爪，画面上方留出空白区域（之后叠加符号），中景，浅景深，高品质潮玩盲盒手办质感，超写实3D渲染。负面：文字，符号，多余人物，水印。

**seg2_first_frame.png**：与上一张相同的场景、机位和光线，同一只香蕉猫歪着头看向镜头，竖起一只小猫爪比"厉害"手势，画面右下方留出空白区域，中景，浅景深，高品质潮玩盲盒手办质感，超写实3D渲染。负面：文字，符号，多余人物，水印。
