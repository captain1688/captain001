# 首帧图放这里

两段视频各用一张首帧图，**互不依赖，两段同时提交生成**。

| 文件名 | 用途 |
|---|---|
| `seg1_first_frame.png` | 上段第一帧：香蕉猫躺在睡袋里打哈欠，三盏灯笼都熄灭 |
| `seg2_first_frame.png` | 下段第一帧（＝上段结尾的状态）：香蕉猫坐起来捂眼偷看，前两盏灯笼亮着 |

apimart 的接口里，"首帧图"和"参考图"不能同时用。所以香蕉猫的长相、灯笼的亮灭状态，都要在首帧图里画对。生成首帧图时，把香蕉猫的参考图一起喂给图片模型。

---

## seg1_first_frame.png 图片提示词

```text
竖屏9:16，夜晚的后院草地上搭着一顶小小的米白色露营帐篷，帐篷门帘敞开，里面铺着软垫；帐篷门口上方横拉一根细绳，绳上从左到右挂着三盏半透明软纸灯笼：红色加号形、红色爱心形、金色五角星形，三盏都熄灭、暗暗的，但形状清晰可辨；帐篷里，参考图中的香蕉猫（弯弯的黄色香蕉身体带浅褐色小斑点，白色圆润猫头，大泪眼、粉色小鼻子、白胡须、小三角耳）戴着浅蓝色带小绒球的睡帽，裹在天蓝色小睡袋里躺着，只露出猫头，正张大嘴打哈欠；背景深蓝色夜空、点点繁星、远处虚化树影；中景，浅景深，高品质潮玩盲盒手办质感，超写实3D渲染，色彩温馨梦幻。
负面：灯笼发光，灯笼顺序错误，人类，手，白天，文字，水印，阴暗恐怖
```

## seg2_first_frame.png 图片提示词

先出 seg1 的首帧，满意后**把它当参考图**喂进去，再出这张。这样场景、机位和香蕉猫能保持一致，只改动作和灯笼亮灭。

```text
竖屏9:16，与参考图完全相同的夜晚露营帐篷场景、机位、光线和色调；帐篷门口细绳上从左到右三盏半透明软纸灯笼：红色加号形和红色爱心形两盏已经亮起，发出暖红和粉红的光洒进帐篷，金色五角星形那盏仍然熄灭；帐篷里，同一只香蕉猫坐在软垫上，戴着浅蓝色带小绒球的睡帽，下半身还裹在天蓝色小睡袋里，两只小白猫爪捂着眼睛，但爪子之间张开一条缝偷看，嘴角上扬；背景深蓝夜空、繁星、虚化树影；中景，浅景深，高品质潮玩盲盒手办质感，超写实3D渲染，色彩温馨梦幻。
负面：第三盏灯笼发光，前两盏灯笼不亮，灯笼顺序错误，人类，手，白天，文字，水印，阴暗恐怖
```
