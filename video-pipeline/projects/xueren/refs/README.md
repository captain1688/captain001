# 首帧图放这里

两段视频各用一张首帧图，**互不依赖，两段同时提交生成**。

| 文件名 | 用途 |
|---|---|
| `seg1_first_frame.png` | 上段第一帧 |
| `seg2_first_frame.png` | 下段第一帧（＝上段结尾的画面状态） |

apimart 的接口里，"首帧图"和"参考图"不能同时用。所以咕咕嘎嘎和雪人的长相、纽扣的亮灭状态，都要在首帧图里画对。生成首帧图时，把咕咕嘎嘎的参考图一起喂给图片模型。

---

## seg1_first_frame.png 图片提示词

```text
竖屏9:16，冬日小院的雪地，白雪厚厚蓬松，空中飘着细小雪花，背景是覆雪的松树和小木屋虚化，淡蓝天空，雪面有晶莹反光和柔和投影；画面中，参考图中的咕咕嘎嘎站在一个和她差不多高的雪人旁边，开心地用小手拍着雪人圆圆的肚子；雪人上下两层雪球，两颗黑色圆煤球眼睛，一根橙色胡萝卜鼻子，两根细树枝手臂自然垂着；雪人胸前从上到下竖排三颗冰糖纽扣：最上面红色加号形、中间红色爱心形、最下面金色五角星形，三颗都暗暗的、像蒙了一层薄霜，但形状清晰可辨；中景，浅景深，高品质潮玩盲盒手办质感，超写实3D渲染，色彩明亮清新。
负面：纽扣发光，纽扣顺序错误，雪球，扔雪球的手，帽子，围巾，多余人物，文字，水印，阴暗
```

## seg2_first_frame.png 图片提示词

**要和上段结尾的状态完全一致**，否则两段拼起来会跳。

```text
竖屏9:16，与上一张完全相同的冬日小院雪地场景、机位、光线和色调，空中飘着细小雪花，背景覆雪松树和小木屋虚化，淡蓝天空；参考图中的咕咕嘎嘎站在雪人旁边，双手捧着脸颊，眼睛瞪得圆圆的，嘴角上扬；雪人站在原地，一根树枝手臂举在半空；雪人胸前从上到下三颗冰糖纽扣：最上面的红色加号形纽扣和中间的红色爱心形纽扣已经亮起、晶莹发光，最下面的金色五角星形纽扣仍然暗着、像蒙了一层薄霜；中景，浅景深，高品质潮玩盲盒手办质感，超写实3D渲染，色彩明亮清新。
负面：第三颗纽扣发光，前两颗纽扣不亮，纽扣顺序错误，扔雪球的手，帽子，围巾，多余人物，文字，水印，阴暗
```

**出图技巧：** 先出 seg1 的首帧，满意后把它作为参考图，再喂给图片模型出 seg2 的首帧。这样场景、机位、雪人和咕咕嘎嘎都能保持一致，只改动作和纽扣亮灭。
